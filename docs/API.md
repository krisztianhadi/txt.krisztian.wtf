# API / endpoints

Static site - there is no backend API. Everything below is plain files
served by GitHub Pages.

| Path | Content |
| --- | --- |
| `/` | Homepage: intro + latest posts |
| `/<slug>/` | A post (slug = filename minus date prefix) |
| `/feed.xml` | RSS 2.0 feed (site title, latest 20 posts, full content) |
| `/assets/css/style.css` | Local stylesheet (light + auto night mode) |
| `/assets/images/*` | Post images |
| `/favicon.svg` | Serif-K favicon (vector; generated by `tools/gen-favicon.py`) |
| `/favicon-32.png` | Favicon fallback, 32px |
| `/favicon.ico` | Legacy ico (16 + 32) |
| `/apple-touch-icon.png` | 180px touch icon |
| `/robots.txt`, etc. | only if files are added at the root |

## RSS

- Channel: `title` (krisztian.txt), `link` (https://txt.krisztian.wtf),
  `description`, `language` (en), `lastBuildDate`, `managingEditor`
  (Krisztian).
- Items: `title`, `link`, `guid` (permalink), `pubDate` (RFC 822,
  Asia/Bangkok offset), `author`, `description` (full rendered HTML,
  CDATA-wrapped).
- Autodiscovery: `<link rel="alternate" type="application/rss+xml">` is
  present in every page `<head>`.
- Sources of truth: `_config.yml` (title/url/author/description),
  `feed.xml` template, `_posts/`.
- Generate/fix: edit `feed.xml`, rebuild. No external feed service.
